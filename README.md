# SacredBild+

An "improved" and my own version of SacredBild with the objective of minimizing the "slop" and inserting QoL features.

And as expected, this is obviously AI assisted.

## New features
- Support for >60FPS in the menu.
- Fullscreen mode.
- Menus and loading screens fill the whole screen (no 4:3 bars).
- Skip the intro logo movies.
- Lobby server switcher in the multiplayer menu.
- Active effects next to the portrait, with time left and the name on hover.
- Colors and icons in character names (right click the name field).
- Text boxes: movable caret, selection, copy and paste.
- Reworked settings window.

## Fixes
- SMAA no longer washes out the image.
- Screenshots no longer make the animations jump.
- The game window no longer hangs as "not responding" at start.
